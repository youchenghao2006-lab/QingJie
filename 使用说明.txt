轻截 2.4 — 截图、标注、贴屏与自由画布

开始使用
双击 QingJie.exe；便携版，无需安装。
请把程序和 QingJie.exe.config 保存在同一个文件夹。
运行环境：Windows 10 / 11，.NET Framework 4.8。
界面优先使用本机 MiSans 字体，没有时自动使用等线或微软雅黑。

快捷截图：默认单按 F2
• 在主窗口或后台运行时，按 F2 即可框选屏幕区域。
  前台按 F2 会保留轻截界面，直接截取当前看到的画面，不会先隐藏窗口。
• 按住左键拖动框选，松开后进入快速调整与标注。
• 初始为「调整」模式，拖动选区边缘或四角可重新调整截图范围。
  拖动选区内部可整体移动选区，鼠标靠近边缘或角点时会高亮对应手柄。
  扩大范围会取出这次截图时冻结的屏幕内容，不会拉伸截图像素。
• 选择画笔、箭头、矩形、马赛克或文字后即可标注。
  要再次调整范围，点击「调整」；已有标注保留在原来的屏幕位置。
• 框选和标注期间，选区之外保持暗色遮罩；结束快速标注或取消后恢复原屏幕。
• 选区右下方显示单排图标工具条，鼠标悬停可看中文功能名称。
  屏幕边缘空间不足时自动换到上方或移入屏幕内；较窄屏幕用「更多」收纳按钮。
• 「撤回」撤销最近一次标注；「还原」恢复撤销的标注；「清除」恢复无标注截图。
• 复制或 Enter：复制当前结果并结束快速标注；保存：另存图片并继续编辑。
• 贴屏：把当前结果固定到桌面上；编辑器：把结果送入主窗口继续编辑。
• 退出 / Esc：关闭待确认截图；不会退出整个轻截。
• 快捷键截图只有在复制、保存、贴屏或送入编辑器时，才把最终结果加入历史。
  退出未确认选区不生成历史图片，避免保留初选、调整过程中的重复图片。
• 背景中的普通窗口内容变化不会更新冻结截图。要抓取新画面，请重新截图。

滚动长截图
• 在主窗口左侧或托盘右键菜单点「滚动长截图」，从希望保留的起点框选网页、文档或聊天记录的正文。选区至少宽 32 像素、高 64 像素。
• 也可以按 F2 框选，调整好大小后点单排工具条的「滚动长截图」。这个入口使用当前选区。已有标注时可以先保存，然后清除标注再开始。
• 把鼠标放在原页面上，手动向下滚动。若滚轮没反应，先单击正文空白处。每次保留一段重叠内容，尽量避开滚动条和不断变化的区域。
• 滚动期间可在原页面操作，选区外轻微变暗。选区右下角附近的小预览显示已拼接的图片和高度。提示「未接上」时，往回滚到上一段，再缓慢向下滚。
• 到末尾点「完成」或按 Ctrl + Enter。按 Esc 取消会保留之前的编辑内容。框选占满屏幕时仍可使用快捷键。
• 完成的长图自动进入编辑器、截图队列及「历史记录\截图」。如果末屏未对齐或达到尺寸上限，编辑器会提示哪一部分已保留。
• 支持纵向滚动。长图高度最多 32767 像素，整图最多 8000 万像素。

修改快捷键与关闭行为
• 点击左侧「设置」，点击快捷键框后直接按想使用的键，保存即可生效。
• 支持 F1–F24，或带 Ctrl / Alt 的字母、数字等组合；可一键恢复 F2。
• 快捷键被其他程序占用时会明确提示，并保留原绑定。
• 关闭主窗口默认询问「后台运行」「退出程序」或「取消」。
  后台运行会保留本次截图队列、编辑状态和自由画布。
• 设置里可改为每次询问、直接进入后台或直接退出。
• 最小化会进入系统托盘；双击托盘图标可打开主窗口。
  托盘右键还可以截图、查看历史、打开设置或退出轻截。
• 程序运行时快捷键才生效。退出程序后快捷键自动释放。
• 设置保存在同目录的 settings.ini，更新软件时应保留这个文件。

固定在屏幕上的图片
• 按住图片任意位置拖动，可自由移动到不同显示器。
• 贴屏后只显示图片。滚轮围绕鼠标所在位置缩放，按 Ctrl + 0 恢复原始查看比例。
• 右键提供复制、保存、原始尺寸、33% / 50% / 100% / 200% 缩放、
  左右旋转、水平 / 垂直镜像、透明度及关闭贴图。
• 图片有细边框和窗口阴影，始终置顶；可同时保留多张贴图。
• Ctrl + C 复制，Ctrl + S 保存，Ctrl + 0 恢复原尺寸，Esc 关闭当前贴图。
• 查看缩放不改变图片本身的分辨率；复制/保存使用图片当前旋转、镜像后的像素。
• 贴图只是本次运行的悬浮窗口。需要之后继续使用的图片可从历史重新导入。

主窗口截图与标注
• 从界面点击「框选截图」时，轻截先收起主窗口、历史窗口及操作提示，再开始框选。
• 左侧「截取当前屏幕」只截点击时鼠标所在的显示器，不会合并另一块屏幕。
  自由画布里已移除重复的当前屏幕按钮，两种工作区共用左侧入口。
• 延时截图可选择 3 / 5 / 10 秒；目标显示器在开始时锁定。
• 框选期间 Esc / 右键取消。延时期间可从托盘取消。
• 画框、箭头、平滑画笔、马赛克、文字；颜色和粗细可选择。
• 马赛克支持像素方块、柔化模糊、圆点、斜纹和纯色遮挡。
  强度独立于画笔粗细；纯色遮挡始终完全覆盖。
• 再次点击当前工具，或按 Esc，可退出标注。
• Ctrl + Z 撤销，Ctrl + Y 还原，Ctrl + O 打开图片，Ctrl + V 粘贴。
• Ctrl + S 保存 PNG / JPEG；Ctrl + C 复制到剪贴板。
• 主窗口的截图成功后自动存入历史，编辑后的复制/保存也会保留输出版本。
• 删除截图会清空当前编辑器和对应队列条目，已保存的历史图片仍保留。
  没有保留副本的未保存编辑，删除前会提示确认。
• 图片按窗口适配预览，导出保持原始像素尺寸。

历史图片：两个独立文件夹
图片保存在程序文件夹中：
  历史记录\截图\  — 屏幕截图与截图编辑结果
  历史记录\画布\  — 自由画布导出、复制生成的合成图

• 点击左侧或画布顶部的「历史图片」，切换全部 / 截图 / 画布分类。
• 双击图片或点「在编辑器打开」可继续标注任意一类历史图片。
• 多选后点「加入画布」，可一次导入多张截图或画布作品。
  Ctrl 追加选中，Shift 连续选择；两个分类的图片都能用于编辑和画布。
• 历史列表按时间倒序，缩略图只加载可见部分；文件数量多时仍可滚动浏览。
• 点击「刷新」重新读取，点击「打开文件夹」查看图片文件。
• 所有历史都是普通 PNG，退出软件或重启后仍保留；不会自动清理。
• 文件写入在后台完成；真正退出时会等待已提交的保存结束。
• 磁盘空间不足或文件夹不可写时会提示，请复制或另存当前图片。
• 导入的历史合成图可继续追加标注，但不能拆开之前已合成的图层。

自由画布与截图队列
• 左侧「截图编辑」和「自由画布」可随时切换，高亮项表示当前工作区。
• 连续截图、打开图片和粘贴图片会保留在左侧截图队列。
  从队列直接拖到右侧画布；双击或点击加入按钮会放入当前视野附近。
• 「导入多图」、拖入图片文件、粘贴或导入历史，均可添加图片。
• 直接拖动图片调整位置，拖动右下角手柄等比例缩放。
  空白处按住左键拖动可平移整个视野；也可用中键、空格+左键或平移工具。
• 滚轮围绕鼠标缩放，手动范围 10%–400%；「适应内容」显示全部图像和标注。
• 画布没有固定纸张边框，图片和标注可放到任意方向，包括负坐标。
• 箭头、画笔、画框和文字可跨图片绘制；移动图片不会自动移动独立标注。
• Delete 删除选中图片，Ctrl + Z 撤销图片与标注操作。
• 「清空」会移除本次画布全部内容，并要求确认。
• 导出或复制按内容范围生成白底合成图片，四周保留 32 像素留白。
  查看缩放和平移不改变导出分辨率；导出/复制成功后自动加入「历史记录\画布」。
• 单边超过 32767 像素或总面积超过 8000 万像素时会要求缩小内容范围。
• 队列及可编辑的画布布局保存在本次运行内存中，后台运行会保留。
  退出前需要继续使用的画布应先导出或复制；目前不提供可重新编辑的工程文件。

流畅度处理
• 主窗口在显示前完成首帧布局和静态背景准备，减少打开时逐块绘制。
• 前台 F2 不再隐藏窗口；侧栏截图隐藏窗口后才等待桌面合成完成。
• 框选完成后沿用同一暗色背景与冻结图像，减少界面切换和整屏图片复制。
• 连续调整选区合并鼠标输入，只更新最新边界；完整裁剪与笔迹重建放在松手时。
• 平滑画笔只追加新增曲线并局部刷新，长笔迹不会逐帧重算全部点。
• 自由画布合并高频拖动/滚轮输入、复用视口缓冲，高清图在后台细化。
• 贴屏缩放使用缓存预览，停止后恢复清晰细节。
• 历史 PNG 压缩与缩略图读取放在后台，不在滚轮滚动时扫描或解码全部图片。
• 合成测试结果与测量条件见同目录「性能验证.txt」，不等同于真实桌面帧率。

数据与构建
图片仅在本机处理，不上传、不联网。截图和生成结果会按上面的规则自动写入历史。
目前没有云同步、OCR 或录屏。
部分受保护视频及系统安全桌面可能无法捕获。

Source 包含完整 C# WinForms 源代码，不依赖第三方包。
先退出轻截，在此目录的 PowerShell 中运行 .\build.ps1 即可重新构建。
功能测试：.\run-tests.ps1
快速标注/贴屏测试：.\run-quick-capture-tests.ps1
滚动拼接/采集会话测试：.\run-scroll-tests.ps1、.\run-scroll-session-tests.ps1
框选遮罩/双屏边界测试：.\run-region-overlay-tests.ps1
局部刷新回归：.\run-performance-tests.ps1 -RegressionOnly
画布导航压力：.\run-navigation-stress.ps1 -Mode host
